## This is for the Evaluating Officers and the Assistant Evaluaring Officers of the CPEIMU, MPME, Bangladesh Gov't
As the officers need to fill up a form manually to take the data of a school and then again they have to computerize it and then the data report becomes eligible to submit, this site is made to reduce the labour and time for them. This site will take those datas as an input and then it will give them an output which is actually the the final report to submit.
